# Data Analysis & Formula Exercises

## Project Overview
This repository contains an Excel practice workbook demonstrating the use of essential Excel formulas, functions, and data analysis techniques. The exercises focus on product data analysis, logical functions, conditional calculations, and text manipulation.

## Tasks Performed

### Data Analysis
- Calculated the **total price** of all products in the dataset using the `SUM` function.
- Determined the **total number of products** in the dataset using the `COUNT` function.
- Calculated the **average product price** using the `AVERAGE` function.
- Identified the **minimum product price** using the `MIN` function.
- Identified the **maximum product price** using the `MAX` function.

### Logical Functions
- Created a new column named **Price Range** using the `IF` function.
- Categorized products based on their price:
  - **High Price** → Price ≥ $500
  - **Standard Price** → Price < $500

### Conditional Calculations
- Used the `SUMIF` function to calculate the **total price of products in the Electronics category**.
- Used the `COUNTIF` function to determine the **number of products with a price less than $100**.

### Text Functions
Created additional columns by extracting information from the **Product ID**:

#### Day
- Used the `LEFT` function to extract the first 2 characters of the Product ID.

#### Country Code
- Used the `RIGHT` function to extract the last 2 characters of the Product ID.

#### Month
- Used the `MID` function to extract the 4th to 6th characters of the Product ID.

## Excel Functions Used

| Function | Purpose |
|-----------|---------|
| SUM | Calculate total product price |
| COUNT | Count total products |
| AVERAGE | Calculate average price |
| MIN | Find minimum price |
| MAX | Find maximum price |
| IF | Categorize products by price |
| SUMIF | Sum prices based on category |
| COUNTIF | Count products meeting criteria |
| LEFT | Extract first characters from Product ID |
| RIGHT | Extract last characters from Product ID |
| MID | Extract characters from the middle of Product ID |
